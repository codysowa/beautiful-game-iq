# iOS launch checklist

## Already prepared in the repository
- Capacitor 8 iOS shell configuration
- AdMob banner/consent integration
- RevenueCat Premium entitlement integration
- Restore Purchases flow
- Bug reporting and support diagnostics
- Safe-area handling
- Privacy Policy page: /privacy.html
- Terms of Use page: /terms.html
- App version 1.0.0

## Required external setup before App Store submission
1. Apple Developer Program membership
2. App Store Connect app record for bundle ID com.beautifulgameiq.app
3. RevenueCat iOS app, product, entitlement named premium_no_ads, and current Offering
4. AdMob iOS app and banner ad unit
5. AdMob privacy/consent messages and iOS application ID
6. App icon and launch assets
7. App Store screenshots, description, keywords, support URL, and privacy-policy URL

## Important
The RevenueCat SDK key and AdMob identifiers used by the app are public client-side identifiers. Do not put RevenueCat secret API keys or AdMob server credentials in the app.
